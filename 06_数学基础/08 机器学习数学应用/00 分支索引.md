## 一、这一段装什么

从"会算导数"到"看得懂反向传播"。核心认知：**机器学习算法不是新数学，是已有数学在特定结构上的组合应用**。

- 线性回归 = 最小二乘 + 矩阵求导
- 逻辑回归 = Sigmoid + 交叉熵 + 梯度下降
- 神经网络 = 一系列线性变换与非线性激活的复合 + 链式法则
- PCA = 协方差矩阵的特征分解

## 三、这一段与 AI 的关系

| 数学内容 | 用在哪 | 有多必要 |
|---|---|---|
| 矩阵乘法与形状 | 每一层的线性计算 | **必须** |
| 偏导与链式法则 | 反向传播 | **必须** |
| 交叉熵 | 分类损失（语言模型也一样） | **必须** |
| 特征值分解 | PCA、谱方法 | 高 |
| 概率与贝叶斯 | 分类、生成模型 | 高 |
| 梯度下降及其变体 | 训练的全部 | **必须** |

> **必须记住的一条**：深度学习框架替你算梯度，但**看不懂形状与链式法则，就调不动模型**。
