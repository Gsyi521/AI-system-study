## 二、数学不是 AI 的附属品

数学库有三个独立特征：

1. **有自己的首页**（就是本页），入口与 Python / ML 平级，不藏在任何学科目录下。
2. **有自己的编号段**，与学科 ID 互不干扰。
3. **被引用方向是单向的**：学科点引用数学点；数学点不因某个课程存在而存在。

因此本库**不写"某某课程配套数学"**，只写数学本身。课程需要什么，由课程来建链接。

## 五、怎么用这个库

1. **按需取用，不追求体系完整**：卡在哪个公式，就只补那一个点。
2. **先建立几何直觉，再补推导**：线代先想"空间怎么变换"，再写行列式。
3. **每个数学点都要有"被用在哪"**：如果一个数学点没有任何应用侧引用，标注"纯理论，暂缓"。
4. **不要为了看论文而通读教材**：读论文遇到不懂的记号，回这里补一个点即可。
