## 🔗 Obsidian ↔ Notion 如何对齐：知识 ID

两边不做实时双向同步，而是靠一套**统一且永不复用的 ID** 对齐：

| 前缀 | 含义 | 示例 |
|---|---|---|
| `PY-` / `ML-` / `DL-` / `LLM-` | Python / 机器学习 / 深度学习 / 大语言模型知识点 | `DL-042 卷积运算` |
| `MATH-` | 数学知识点，百位表示分支（1xx 高数、2xx 线代、3xx 概率、4xx 统计、5xx 离散、6xx 数值、7xx 最优化、8xx ML 数学应用） | `MATH-216 矩阵乘法` |
| `PROJ-` | 实战项目 | `PROJ-023 搭建一个最小可用的 RAG 问答系统` |
| `REF-` | 参考资料 | `REF-0001 Attention Is All You Need` |
| `M-<学科>-NN` / `RM-NNN` | 课程模块 / 学习路线 | `M-DL-05` / `RM-005` |

- **Obsidian 笔记**：文件名为 `ID 名称.md`，frontmatter 中的 `id` 与 Notion「知识点」库的 `知识ID` 逐字一致。
- **合并方式**：本仓库保留 Obsidian 正文，并把 Notion 属性（学科、学习状态、难度、知识类型、所属模块/路线、前置/后继知识、关联数学/Python、对应项目等）写入 frontmatter；同时在笔记末尾追加「🔗 Notion 同步信息」一节，用**相对链接**列出这些关联，在 GitHub 和 Obsidian 中都能直接点击跳转。
- **结构化数据**：Notion 各数据库完整导出为 CSV，关联字段已转换为 ID（多个值以 `;` 分隔）：

## 🚀 如何使用

**方式一：作为 Obsidian 库打开（推荐）**

1. `git clone` 本仓库（或下载 ZIP 解压）。
2. 在 Obsidian 中选择「打开本地仓库 / Open folder as vault」，指向仓库根目录。
3. 从 [00_知识首页/00 总索引](00_%E7%9F%A5%E8%AF%86%E9%A6%96%E9%A1%B5/00%20%E6%80%BB%E7%B4%A2%E5%BC%95.md) 开始；知识点之间的 `[[ID 名称]]` 双链与关系图谱即可使用。

**方式二：直接在 GitHub 上浏览**

- 点击上表中的目录进入各学科；每篇笔记末尾的「🔗 Notion 同步信息」使用标准 Markdown 相对链接，可在网页上跳转。
- 正文中的 `[[...]]` 是 Obsidian 双链语法，GitHub 不会渲染为链接，可按文件名在对应目录中查找。
- 想做筛选统计时，可直接查看 `data/` 下的 CSV。
