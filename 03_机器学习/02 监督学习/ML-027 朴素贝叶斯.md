# ML-027 朴素贝叶斯

## 1. 本节学习目标

1. 写出朴素贝叶斯的分类规则，说清"朴素"假设是什么。
2. 会用 `GaussianNB`（连续特征）与 `MultinomialNB`（词频）。
3. 理解**零概率问题**与拉普拉斯平滑的必要性（本课 $\alpha=0$ 的实测）。
4. 知道为什么"假设不成立但效果还行"。

## 2. 为什么需要这个知识

因为朴素贝叶斯是**"概率论直接变算法"的最短路径**：贝叶斯公式 + 一个（明显不真实的）独立性假设。

它训练极快、样本需求少、可解释，是文本分类的经典基线。而它的"朴素"假设几乎是错的——理解它**为什么还能用**，是本节的核心。

## 3. 直观解释

判断一封邮件是否垃圾：

$$
P(\text{垃圾}\mid\text{词}) \propto P(\text{垃圾})\cdot\prod_{\text{词}}P(\text{词}\mid\text{垃圾})
$$

- **先验**：历史上垃圾邮件的比例。
- **似然**：垃圾邮件里每个词出现的频率。
- **后验**：看到这些词之后，判断是垃圾的概率。

**"朴素"在哪**：假设**所有词相互独立**（给定类别）。这显然错——"信用"和"卡"几乎总是一起出现。但因为最终只比大小（argmax），错误常被"同向抵消"。

## 4. 正式定义

**分类规则**

$$
\hat y = \arg\max_c\ P(c)\prod_{j=1}^{d}P(x_j\mid c)
$$

**对数形式**（防下溢）

$$
\hat y = \arg\max_c\left[\ln P(c)+\sum_j \ln P(x_j\mid c)\right]
$$

**三种变体**

| 变体 | 似然假设 | 适用 |
|---|---|---|
| `GaussianNB` | $x_j\mid c\sim N(\mu_{jc},\sigma_{jc}^2)$ | 连续特征 |
| `MultinomialNB` | 词频多项分布 | 文本计数 |
| `BernoulliNB` | 0/1 出现与否 | 短文本 |

**拉普拉斯平滑**

$$
P(x_j=v\mid c) = \frac{N_{c,v}+\alpha}{N_c+\alpha|V|}
$$

## 5. 核心原理

**为什么零概率是致命的**：连乘中有 0 ⇒ 整个乘积为 0 ⇒ 该类被"一票否决"，无论其他证据多强。

**平滑怎么救**：$\alpha>0$ 让每个取值至少有 $\alpha$ 的计数，概率永远 $>0$。

**为什么假设错了还能用**：分类只需要**排序正确**（argmax 对就行），不需要概率估计准确。独立性假设会让概率值被系统性放大/压缩，但常常**不改变排序**。

代价：输出的概率**过度自信**（接近 0 或 1），不能直接当置信度用。

## 6. 数学表达式

**本课实验 1**：`GaussianNB` 在 breast cancer 上

$$
\text{acc} = 0.9371
$$

**本课实验 2**：小型文本语料（5 条文档）

词表：`['垃圾','学习','有趣','机器','机器学习','讨厌','邮件']`（7 个 token）

预测"机器 学习 垃圾"：

$$
P(\text{正类}) = 0.7392,\qquad P(\text{负类})=0.2608
$$

**平滑对照**：$\alpha=0$ 时，预测"垃圾 垃圾 垃圾"给出

$$
[1.0,\ 0.0]
$$

即**负类概率被压成 0**——典型的零概率否决。

## 10. Python 实现

```powershell
python ml027_naive_bayes.py
```

```python
import numpy as np
from sklearn.datasets import load_breast_cancer
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.metrics import accuracy_score
from sklearn.model_selection import train_test_split
from sklearn.naive_bayes import GaussianNB, MultinomialNB

# 连续特征
X, y = load_breast_cancer(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42, stratify=y)
gnb = GaussianNB().fit(X_train, y_train)
print("GaussianNB acc:", round(accuracy_score(y_test, gnb.predict(X_test)), 4))

# 文本计数
docs = ["我 爱 机器学习", "机器 学习 很 有趣", "我 讨厌 垃圾 邮件",
        "垃圾 邮件 真 烦", "机器 学习 真 有趣"]
labels = [1, 1, 0, 0, 1]

vectorizer = CountVectorizer()
X_docs = vectorizer.fit_transform(docs)
print("词表:", vectorizer.get_feature_names_out().tolist())

mnb = MultinomialNB(alpha=1.0).fit(X_docs, labels)
query = vectorizer.transform(["机器 学习 垃圾"])
print("预测:", mnb.predict(query).tolist())
print("概率:", mnb.predict_proba(query).round(4).tolist())

mnb_raw = MultinomialNB(alpha=0.0).fit(X_docs, labels)
q2 = vectorizer.transform(["垃圾 垃圾 垃圾"])
print("alpha=0 概率:", mnb_raw.predict_proba(q2).round(4).tolist())
print("alpha=1 概率:", mnb.predict_proba(q2).round(4).tolist())
```

**实际运行结果**

```
GaussianNB acc: 0.9371
词表: ['垃圾', '学习', '有趣', '机器', '机器学习', '讨厌', '邮件']
预测: [1]
概率: [[0.2608, 0.7392]]
alpha=0 概率: [[1.0, 0.0]]
alpha=1 概率: [[0.0, 1.0]]
```

## 11. 代码逐行解释

| 代码 | 作用 |
|---|---|
| `GaussianNB()` | 连续特征，假设每类每维正态 |
| `CountVectorizer()` | 把文本切成"词 → 计数"矩阵 |
| `fit_transform(docs)` | 训练语料上建词表并计数 |
| `transform([...])` | 新文本按**已有词表**编码（不重建） |
| `MultinomialNB(alpha=1.0)` | 拉普拉斯平滑，$\alpha$ 即平滑强度 |
| `alpha=0.0` | 关闭平滑，用来演示零概率 |

**关键对照**：同一条查询"垃圾 垃圾 垃圾"，

- $\alpha=0$ ⇒ `[1.0, 0.0]`（负类概率**精确为 0**，被否决）
- $\alpha=1$ ⇒ `[0.0, 1.0]`（判为负类，但概率不是 0）

**注意**：这里 $\alpha=0$ 与 $\alpha=1$ 给出了**相反**的预测。这不是矛盾，而是"平滑改变了似然估计"，在小语料上影响巨大。

## 12. 实际运行结果

见第 10 节。三点：

1. GaussianNB 在 breast cancer 上 **0.9371**（略低于逻辑回归的 0.9860）。
2. 小语料上 $\alpha$ 从 0 变 1，预测**翻转**（1.0/0.0 → 0.0/1.0）。
3. 词表把"机器学习"与"机器"+"学习"当成不同 token——中文分词问题会直接影响效果。

## 13. 适用场景

| 场景 | 变体 |
|---|---|
| 文本分类（垃圾邮件、情感） | MultinomialNB |
| 短文本/关键词 | BernoulliNB |
| 连续特征、小样本 | GaussianNB |
| 需要极快训练 | 任意 |
| 特征强相关 | 效果会退化（假设被违反） |

## 14. 优点与缺点

| 优点 | 缺点 |
|---|---|
| 训练极快（一遍计数） | 独立性假设常不成立 |
| 小样本也能用 | 概率过度自信（近 0/1） |
| 多分类天然支持 | 特征相关时效果下降 |
| 可解释（看似然） | 连续特征正态假设常不成立 |

## 15. 常见错误

| 错误 | 表现 | 纠正 |
|---|---|---|
| 不做平滑 | 未见词 ⇒ 概率 0 | `alpha=1` |
| 用 MultinomialNB 处理负值 | 报错 | 连续特征用 GaussianNB |
| 概率当置信度 | 总是接近 0/1 | 只用于排序 |
| 中文不分词 | 词表混乱 | 先分词 |
| 在测试集上 `fit_transform` | 泄漏（词表含测试词） | 只 `transform` |
| 特征强相关仍用 NB | 效果不如 LR | 换模型或做特征选择 |

## 16. 本节总结

- 朴素贝叶斯 = 贝叶斯公式 + **特征条件独立假设**。
- 零概率必须用平滑救；本课 $\alpha$ 从 0→1 让预测翻转。
- 假设常不成立，但 argmax 往往仍对——**概率值不可信，排序可用**。

## 18. 练习与参考答案

**基础 1**：朴素贝叶斯的"朴素"指什么假设？为什么这个假设常不成立还能用？

**基础 2**：本课 GaussianNB 在 breast cancer 上的准确率是多少？与逻辑回归相比如何？

**进阶 1**：为什么 $\alpha=0$ 与 $\alpha=1$ 会给出相反的预测？

**综合 1**：中文文本直接喂 `CountVectorizer` 有什么问题？怎么改？

> [!success]- 参考答案

> **基础 1**
> 假设**在给定类别下，各特征相互独立**：$P(x_1,\dots,x_d\mid c)=\prod_j P(x_j\mid c)$。
> 不成立还能用，因为分类只需要 $\arg\max$ 的**排序正确**；独立性假设会扭曲概率的绝对值，但常不改变排序。

> **基础 2**
> GaussianNB **0.9371**；逻辑回归（标准化 + $C=1$）**0.9860**。
> 朴素贝叶斯在这个数据上低约 5 个百分点，主要因为 30 个特征强相关，独立性假设被严重违反。

> **进阶 1**
> 因为 $\alpha$ 改变了似然的估计。小语料里某类没出现过某个词时：
> - $\alpha=0$ ⇒ 该词似然为 0 ⇒ 连乘为 0 ⇒ 该类被否决（`[1.0, 0.0]`）；
> - $\alpha=1$ ⇒ 该词似然被平滑成小正数 ⇒ 不再否决，反而按先验/其他词判定（`[0.0, 1.0]`）。
> 语料只有 5 条，所以平滑的"小修正"足以翻转结论。

> **综合 1**
> 问题：`CountVectorizer` 默认按空格/标点切词，中文整句会被当成一个 token（或切成单字），词表失去语义。
> 修正：先分词（如 jieba），再用空格连接后喂给 `CountVectorizer`，或直接用 `tokenizer=jieba.lcut`。
