## 2. 通俗原理讲解

分组聚合像**把一堆卡片按部门分堆，再分别数一数**：

1. **拆（split）**：按 `dept` 把行分成几堆。
2. **算（apply）**：每堆算平均/计数/最大。
3. **合（combine）**：把结果拼成一张小表。

这正好对应 SQL 的 `GROUP BY`。学会它，Pandas 就能替代大量 Excel 手工透视。

## 3. 技术原理

| 需求 | 写法 |
|---|---|
| 分组后取一列 | `df.groupby("dept")["score"]` |
| 求均值 | `.mean()` |
| 多指标 | `.agg(["count", "mean", "max"])` |
| 命名聚合 | `.agg(平均="mean", 人数="count")` |
| 组大小 | `.size()` |
| 每组第一行 | `.first()` |
| 遍历组 | `for name, group in grouped:` |

**注意**

- `groupby` 默认**丢弃**分组键为 NaN 的行。
- 聚合默认**跳过 NaN**（`skipna=True`）。
- `.mean()` 与 `.agg("mean")` 等价；`.size()` 计入 NaN，`.count()` 不计。
- 结果常是"索引为分组键"的 Series/DataFrame，用 `.reset_index()` 变回普通列。

## 5. 完整代码示例

```powershell
python groupby_demo.py
```

```python
import pandas as pd

g = pd.DataFrame({"dept": ["A", "A", "B"], "score": [80, 90, 70]})

print(g.groupby("dept")["score"].mean().round(2).to_dict())
print(g.groupby("dept")["score"].agg(["count", "mean"]).round(2).to_dict())
print(g.groupby("dept").size().to_dict())
```

**预期输出**

```
{'A': 85.0, 'B': 70.0}
{'count': {'A': 2, 'B': 1}, 'mean': {'A': 85.0, 'B': 70.0}}
{'A': 2, 'B': 1}
```

**说明**

- `.to_dict()` 把结果转成字典，便于对照阅读。
- `.agg(["count","mean"])` 一次算两个指标，结果是"指标为列"的表。
- `.size()` 数行数（含 NaN），`count()` 数非空值。

## 6. 实践练习

**基础**

1. 按部门求平均分。
2. 按部门统计人数与最高分。
3. 用 `reset_index()` 把分组结果变回普通表。

**进阶**

1. 用命名聚合输出 `人数`、`平均分` 两列。
2. 说明 `size()` 与 `count()` 在含 NaN 时的差异。

**综合实践**

给一张"销售记录表"（region、product、amount），输出：每个 region 的总销售额、每个 region 的订单数、每个 (region, product) 组合的销售额，并按销售额降序排出前 3 个 region。

## 7. 参考答案

**基础 1 · 思路**：`mean`。

```python
import pandas as pd
g = pd.DataFrame({"dept": ["A", "A", "B"], "score": [80, 90, 70]})
print(g.groupby("dept")["score"].mean().round(2).to_dict())
```

运行结果：`{'A': 85.0, 'B': 70.0}`

**基础 2 · 思路**：多指标。

```python
print(g.groupby("dept")["score"].agg(["count", "max"]).to_dict())
```

运行结果：`{'count': {'A': 2, 'B': 1}, 'max': {'A': 90, 'B': 70}}`

**基础 3 · 思路**：`reset_index`。

```python
out = g.groupby("dept")["score"].mean().reset_index()
print(out.columns.tolist())
```

运行结果：`['dept', 'score']`

**进阶 1 · 思路**：命名聚合。

```python
print(g.groupby("dept").agg(人数=("score", "count"), 平均分=("score", "mean")).to_dict())
```

运行结果：`{'人数': {'A': 2, 'B': 1}, '平均分': {'A': 85.0, 'B': 70.0}}`

**进阶 2 · 思路**：是否计空。

答案：`size()` 数所有行（含 NaN），`count()` 只数非空值；数据无缺失时相同。

**综合实践 · 思路**：三次 groupby。

```python
import pandas as pd

df = pd.DataFrame({
    "region": ["东", "东", "西", "西", "北"],
    "product": ["A", "B", "A", "A", "B"],
    "amount": [100, 200, 150, 50, 80],
})

print("按 region 总额:", df.groupby("region")["amount"].sum().to_dict())
print("按 region 订单数:", df.groupby("region").size().to_dict())
print("region+product:", df.groupby(["region", "product"])["amount"].sum().to_dict())

top3 = df.groupby("region")["amount"].sum().sort_values(ascending=False).head(3)
print("前 3:", top3.to_dict())
```

运行结果：

```
按 region 总额: {'东': 300, '西': 200, '北': 80}
按 region 订单数: {'东': 2, '西': 2, '北': 1}
region+product: {('东', 'A'): 100, ('东', 'B'): 200, ('西', 'A'): 200, ('北', 'B'): 80}
前 3: {'东': 300, '西': 200, '北': 80}
```

## 8. 常见错误

| 错误写法 | 现象 | 原因 | 正确写法 |
|---|---|---|---|
| 忘记选列就 `mean()` | 得到整表聚合 | 未指定列 | `groupby("dept")["score"]` |
| 想按列保留却直接 `to_dict` | 索引变键 | 结果是"索引=分组键" | `.reset_index()` |
| 以为 `count` 数行 | 少了 NaN | 只数非空 | 行数用 `size()` |
| 分组键含 NaN 消失 | 少一组 | 默认丢弃 | `dropna=False` |
| 对文本列求均值 | 报错 | 非数值 | 先筛选数值列 |
