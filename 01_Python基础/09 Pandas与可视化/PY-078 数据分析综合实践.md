## 2. 通俗原理讲解

单点技能（筛选、分组、画图）都会了，真实工作的难点是**把它们串成流水线**。

一条标准的数据分析流水线：

```
拿到数据 → 看结构 → 清洗 → 计算指标 → 出图 → 写结论
```

**顺序不能乱**：先清洗再统计，否则缺失值会污染均值；先想清楚要回答什么问题，再决定画什么图。

## 3. 技术原理

| 阶段 | 常用操作 |
|---|---|
| 看结构 | `shape`、`dtypes`、`head()`、`isna().sum()` |
| 清洗 | `dropna`、`fillna`、`astype`、`to_datetime` |
| 计算 | `groupby().agg()`、`sort_values`、`pivot_table` |
| 出图 | `subplots` + `bar` / `plot` |
| 汇报 | 关键数字 + 一句结论（不是把图甩出去） |

**本实践的验收点不是"图画出来了"，而是**：

1. 缺失值是否**说明**了怎么处理、为什么。
2. 统计口径是否清楚（天数？订单数？去重人数？）。
3. 结论是否能从数据里读出来，而不是猜。

## 5. 完整代码示例

```powershell
python analysis_case.py
```

```python
from pathlib import Path

import matplotlib

matplotlib.use("Agg")
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd

rng = np.random.default_rng(0)
dates = pd.date_range("2026-01-01", periods=90, freq="D")
sales = rng.integers(50, 200, size=90).astype(float)
sales[[3, 10, 20]] = np.nan

df = pd.DataFrame({"date": dates, "sales": sales})
print("原始行数:", len(df), "缺失:", int(df["sales"].isna().sum()))

df = df.dropna(subset=["sales"])
df["month"] = df["date"].dt.to_period("M").astype(str)
summary = df.groupby("month")["sales"].agg(天数="count", 总额="sum")
print(summary.shape, summary.columns.tolist())

fig, ax = plt.subplots(figsize=(5, 3))
ax.bar(summary.index, summary["总额"])
ax.set_title("Monthly Sales")
ax.set_ylabel("Total")
p = Path("summary.png")
fig.savefig(p, dpi=90)
plt.close(fig)
print("图生成:", p.exists())
p.unlink()
```

**预期输出**

```
原始行数: 90 缺失: 3
(3, 2) ['天数', '总额']
图生成: True
```

**说明**

- 用固定随机种子造数据，保证每次运行结果一致（可复现）。
- 本轮**不打印具体金额**：数值会随种子/算法变化，写死等于伪造；这里只验证流程与形状。
- `dropna(subset=["sales"])` 只按销售额列判空，不会误删其它列有空的合法行。
- `to_period("M")` 生成"2026-01"这样的月份标签，适合分组。

## 6. 实践练习

**基础**

1. 把上面的数据按月统计"天数"与"总额"，打印形状。
2. 找出销售额最高的月份（用 `idxmax`）。
3. 判断：为什么要先 `dropna` 再 `groupby`？

**进阶**

1. 改用"周"为粒度（`to_period("W")`），比较月与周两种粒度的信息量。
2. 给柱状图加一条"月均目标线"，并说明基准线的作用。

**综合实践**

写一个完整的小报告程序：

- 造 120 天的销售数据（含 5 个缺失）；
- 清洗并补充说明处理了几行；
- 按月与按周各算一次总额；
- 画 1×2 子图（左月、右周）；
- 输出 3 条文字结论（如"最高月份是 X""月波动大于周波动""共处理 N 行"）。

## 7. 参考答案

**基础 1 · 思路**：`groupby` + `agg`。

```python
print(summary.shape)
print(summary.columns.tolist())
```

运行结果：

```
(3, 2)
['天数', '总额']
```

**基础 2 · 思路**：`idxmax`。

```python
print(summary["总额"].idxmax())
```

运行结果：输出月份字符串（如 `2026-03`，具体取决于数据）。

**基础 3 · 思路**：缺失会污染统计。

答案：`groupby().sum()` 默认跳过 NaN，但 `count()` 与 `size()` 结果不同，容易把"有记录天数"和"日历天数"混淆；先按明确规则清洗，口径才一致。

**进阶 1 · 思路**：换 `freq`。

```python
df["week"] = df["date"].dt.to_period("W").astype(str)
print(df.groupby("week")["sales"].count().shape)
```

运行结果：约 13 行（90 天 ≈ 13 周），比按月（3 行）更细。

**进阶 2 · 思路**：`axhline`。

```python
ax.axhline(summary["总额"].mean(), color="red", linestyle="--")
```

作用：让读者一眼看出哪些月高于平均，而不是只看柱高。

**综合实践 · 思路**：完整流水线。

```python
from pathlib import Path
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd

rng = np.random.default_rng(7)
dates = pd.date_range("2026-01-01", periods=120, freq="D")
sales = rng.integers(50, 200, size=120).astype(float)
sales[[1, 20, 40, 60, 80]] = np.nan
df = pd.DataFrame({"date": dates, "sales": sales})

before = len(df)
df = df.dropna(subset=["sales"])
print(f"清洗：{before} → {len(df)} 行（删除 {before - len(df)} 行）")

df["month"] = df["date"].dt.to_period("M").astype(str)
df["week"] = df["date"].dt.to_period("W").astype(str)
m = df.groupby("month")["sales"].sum()
w = df.groupby("week")["sales"].sum()

fig, axes = plt.subplots(1, 2, figsize=(9, 3))
axes[0].bar(m.index, m.values)
axes[0].set_title("Monthly")
axes[1].plot(w.index, w.values)
axes[1].set_title("Weekly")
plt.setp(axes[1].get_xticklabels(), rotation=45, ha="right")
fig.tight_layout()
p = Path("report.png")
fig.savefig(p, dpi=90)
plt.close(fig)

print("最高月份:", m.idxmax())
print("月波动大于周波动:", m.std() > w.std())
print("图生成:", p.exists())
p.unlink()
```

运行结果（数值随种子固定，但具体大小会随版本变化，故只断言结构）：

```
清洗：120 → 115 行（删除 5 行）
最高月份: <某月>
月波动大于周波动: True/False（取决于数据）
图生成: True
```

> 注意：`m.std()` 与 `w.std()` 的量级不可直接比（月是月合计、周是周合计），严格比较应先归一化到"日均"。这是本笔记留下的一个思考点。

## 8. 常见错误

| 错误写法 | 现象 | 原因 | 正确写法 |
|---|---|---|---|
| 先分组后清洗 | 统计含缺失 | 顺序错 | 先清洗 |
| 用 `size()` 当"天数" | 口径错 | size 数行 | 明确用 `nunique()` 或 `count()` |
| 月合计与周合计直接比波动 | 结论错 | 量级不同 | 归一化后再比 |
| 图无标题/单位 | 无法解读 | 缺上下文 | 标题 + 轴标签 |
| 不设随机种子 | 每次结果不同 | 不可复现 | `default_rng(seed)` |
