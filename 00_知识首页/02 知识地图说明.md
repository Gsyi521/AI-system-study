# 知识地图说明

> 本页是**使用手册**：链接怎么写、ID 怎么用、图谱怎么读、新知识点怎么加。

---

## 一、这个库的三条硬规则

1. **一个知识点 = 一个文件**，文件名 `ID 中文名.md`（如 `PY-001 变量与赋值.md`）。
2. **ID 是唯一契约**，改名可以，改 ID 不行。ID 权威表在 [[08_知识索引/08 ID注册表\|ID 注册表]]。
3. **链接用 Wikilink，不用绝对路径**。移动文件后 Wikilink 会自动跟随。

## 二、链接为什么必须写全路径

本库存在多个同名索引文件（每个学科都有 `00 模块索引.md`，每个数学分支都有 `00 分支索引.md`）。
如果只写 `[[00 模块索引]]`，Obsidian 无法判断你指哪一个，会链到错误页面。

**正确写法（带目录，去掉 `.md`）**：

```markdown
[[01_Python基础/00 模块索引|Python 模块索引]]
[[03_机器学习/00 模块索引|机器学习模块索引]]
[[06_数学基础/02 线性代数/00 分支索引|线性代数]]
[[06_数学基础/00 数学库首页|数学库首页]]
```

**在表格里**：竖线要转义，写成 `\|`：

```markdown
| 入口 | [[01_Python基础/00 模块索引\|Python]] |
```

**知识点之间**（文件名唯一，可直接写文件名）：

```markdown
[[PY-001 变量与赋值]]
[[MATH-216 矩阵乘法]]
```

## 三、四类链接，各管一件事

| 类型 | 写在哪 | 作用 | 示例 |
|---|---|---|---|
| **前置** | 正文"知识关联"节 | 说明"学它之前得会什么" | `[[MATH-121 导数]]` |
| **后继** | 正文"知识关联"节 | 说明"学完能往哪走" | `[[ML-002 梯度下降]]` |
| **数学依赖** | 正文"数学基础"节 + frontmatter `related_math` | 学科点挂到数学地基上 | `[[MATH-216 矩阵乘法]]` |
| **实战应用** | 正文"知识关联"节 | 挂到项目 | `[[07_实战项目/00 项目总览\|项目]]` |

反向关联（谁引用了我）**不用手写**，Obsidian 的 Backlinks 会自动汇总。手写反向清单只会腐烂。

## 四、ID 怎么读

| ID | 读法 |
|---|---|
| `PY-001` | Python 第 001 号 |
| `ML-001` | 机器学习第 001 号 |
| `MATH-216` | 数学 · **2xx = 线性代数** · 段内第 16 号 |
| `MATH-121` | 数学 · **1xx = 高等数学** · 段内第 21 号 |
| `M-PY-01` | Python 第 1 个课程模块 |
| `T-0001` | 第 1 个练习任务 |
| `PROJ-001` | 第 1 个实战项目 |

数学的百位就是学科：`1xx` 高数、`2xx` 线代、`3xx` 概率、`4xx` 统计、`5xx` 离散、`6xx` 数值、`7xx` 最优化。
**`MATH-201` 一定是线代，`MATH-121` 一定是高数**——ID 自带你永远不用查表。

## 五、图谱怎么读

打开左侧 Graph View 后：

1. **先看孤岛**：没有任何连线的点 = 没建关联的笔记，要么补链接，要么说明它还不该存在。
2. **再看枢纽**：连线最多的点通常是"数学地基"（如线性代数分支），说明你的知识真的挂在地基上。
3. **最后看方向**：从 Python 指向 ML、从数学指向 DL 的边，应该构成一条主轴，而不是一团乱麻。

建议在图谱设置里把 `06_数学基础` 单独上色（蓝紫 `#6B4FBB`），一眼能看出"这个知识点有没有数学支撑"。

## 六、新增一个知识点的标准动作

1. **查号**：在 [[08_知识索引/08 ID注册表\|ID 注册表]] 找该域下一可用号，**先登记再用号**。
   **注册表是唯一权威**：不得根据文件名、目录顺序、上一篇的编号去"推算"下一个号，也不得让自动化工具自行猜号。
2. **建文件**：复制 [[09_资源素材/templates/知识点模板|知识点模板]]，文件名 `ID 中文名.md`，填 frontmatter。
3. **写正文**：按 17 节结构写，第 5 节按实际需要填数学依赖。
4. **建链接**：只建有真实语义的关联——前置、后继、数学依赖各自"有则写、无则留空"（见第 15 节说明）。
5. **改索引**：在对应 `00 模块索引.md` 的知识点清单里加一行。
6. **跑检查**：运行 `check_links.py`，确认无新增断裂链接、且新 ID 已在注册表登记。

## 七、状态值怎么用

| status | 含义 | 判定标准 |
|---|---|---|
| `planned` | 规划中 | 知道要学，还没开始 |
| `learning` | 学习中 | 正在读/看，还没跑通代码 |
| `understood` | 已理解 | 能复述原理，能解释为什么 |
| `practiced` | 已实践 | 自己写过代码/做过题，跑通过 |
| `mastered` | 已掌握 | 能讲给别人听，能迁移到新场景 |
| `review` | 待复习 | 学过但已生疏，需要回炉 |

**不要跳级**：没 `practiced` 就标 `mastered`，等于自欺。

## 八、健康检查

每完成一批笔记，运行一次：

```powershell
python <USER_HOME>\Documents\deepseek-harness\default-workspace\ai-knowledge-system\tools\check_links.py
```

结果写入 [[08_知识索引/07 链接健康报告\|链接健康报告]]。
它会查：断链、重号、缺 ID、格式错、缺 frontmatter、相对路径失效、孤立页、数学关联悬空。

> 检查器**只读**，不会自动改你的笔记。发现问题由你决定怎么修。
