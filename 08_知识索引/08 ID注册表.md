## 三、编号族规则

| 族 | 格式 | 示例 | 位数 |
|---|---|---|---|
| 知识点 | `<域码>-<NNN>` | `PY-001`、`MATH-216` | 三位（超 999 升四位） |
| 课程模块 | `M-<域码>-<NN>` | `M-PY-01` | 两位 |
| 学习路线 | `RM-<NNN>` | `RM-001` | 三位 |
| 练习任务 | `T-<NNNN>` | `T-0001` | 四位 |
| 实战项目 | `PROJ-<NNN>` | `PROJ-001` | 三位 |

**格式约束**：ID 只能含 ASCII 大写字母与数字，分隔符为半角连字符。**禁止**出现 `x`、`X`、`?`、`*` 等占位字母（`MATH-1xx` 只在规范文档的区间说明中出现，不是正式 ID）。

## 七、登记流程（五步）

> [!important] 唯一权威原则
> **本页是 ID 分配的唯一权威来源。** 任何新增知识点必须先在本页登记、再创建文件。
> **禁止**根据文件名、目录顺序、上一号加一、或任何"看起来合理"的推算来分配编号；
> 自动化工具（Harness / 脚本）**不得自行猜号**，只能读取本页登记结果。
> 检查器会对"未登记 ID"直接报错（R8），并在报告中点名。

1. **查号**：查第六节，取该域下一个可用号。
2. **占号**：在本页登记（第四节为预留，第五节为正式）。
3. **建笔记**：按 [[09_资源素材/templates/知识点模板\|知识点模板]] 写，`id` 字段与登记值**逐字一致**。
4. **回填索引**：[[08_知识索引/00 全知识点索引\|全知识点索引]] + 学科分索引 + 对应 `00 模块索引.md`。
5. **校验**：运行 `check_links.py`，确认无重号、无格式错、且新 ID 已被识别为"已登记"。

## 八、禁止事项

| 禁止 | 原因 |
|---|---|
| 使用未登记的 ID | 会在健康报告里变成"引用悬空" |
| 同一知识点占两个 ID | 重号检查会报冲突，且引用会分叉 |
| 改名后改 ID | 断掉所有引用；改名只改文件名与 `title` |
| 复用已废弃的 ID | 会让历史引用指向错误内容 |
| 用 `xxx` / `00x` 形式占位 | 格式违规，扫描器直接报错 |
| 为"还不存在的知识点"预先发号 | 造成大量空号与虚假进度 |
