## 五、本域特有约定

1. **理论笔记必须配一条"最小可运行验证"**：讲完反向传播，就要有一段能打印出梯度的代码。
2. **形状（shape）必须显式写出**：所有张量运算笔记要标注输入输出形状，形状错是最高频错误。
3. **训练失败要分类**：第 14 节"常见错误"按"数据问题 / 模型问题 / 优化器问题 / 超参问题"四类组织。
4. **不写框架 API 手册**：PyTorch 笔记只写"为什么这样组织训练循环"，不抄文档。
