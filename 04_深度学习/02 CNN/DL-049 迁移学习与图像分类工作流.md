# DL-049 迁移学习与图像分类工作流

## 1. 本节学习目标

1. 说清迁移学习的三种做法：**冻结特征 / 微调 / 从头训**。
2. 用实测看差异（本课：从零 **0.6947**、冻结 **0.8789**、微调 **0.8632**）。
3. 理解"何时冻结、何时微调"的判断依据（数据量 + 相似度）。
4. 会写一条完整的图像分类工作流（数据 → 增强 → 模型 → 训练 → 评估）。

## 2. 为什么需要这个知识

因为**真实项目几乎没有百万级数据**：你手上可能只有几百张图。

从零训 CNN 在这种规模上必然过拟合；而**用预训练权重**能立刻把准确率拉高一个档——本课实测 **0.6947 → 0.8789**（+18.4 个点）。

## 3. 直观解释

**迁移学习 = 借别人在海量数据上学到的"视觉常识"**：

```text
预训练模型（ImageNet 1000 类）已经学会：边缘、纹理、形状…
       ↓ 这些特征对大多数视觉任务都有用
换成你自己的分类头（比如 5 类）
```

**三种做法**：

| 做法 | 冻结什么 | 适用 |
|---|---|---|
| **特征提取** | 冻结全部卷积层，只训分类头 | 数据少、任务相似 |
| **微调（fine-tune）** | 解冻部分/全部层，用小 lr | 数据中等、任务有差异 |
| **从头训** | 不用预训练 | 数据大、任务差异大 |

## 4. 正式定义

**特征提取**

$$
\theta_{\text{backbone}}\ \text{固定},\qquad
\min_{\theta_{\text{head}}}\ \frac1N\sum_i\ell\big(f_{\theta_{\text{head}}}(g_{\bar\theta}(x_i)),y_i\big)
$$

**微调**（解冻全部，但用小学习率）

$$
\min_{\theta}\ \frac1N\sum_i\ell\big(f_\theta(x_i),y_i\big),\qquad \eta_{\text{backbone}}<\eta_{\text{head}}
$$

## 5. 核心原理

**本课实测（合成"条纹方向"任务：A 预训练 400 样本、B 目标仅 10 样本、噪声 1.2）**

```text
预训练(A) test acc: 1.0
从零(B)    test acc: 0.6947
冻结卷积(B) test acc: 0.8789
全量微调(B) test acc: 0.8632
```

**另一组（B 用 20 样本）**：

```text
从零 0.7889 / 冻结 0.8333 / 微调 0.9389
```

**四个读法**：

1. **数据极少（10 条）时，冻结特征最稳（0.8789）**——微调反而略低（0.8632），因为参数多、易过拟合。
2. **数据稍多（20 条）时，微调反超（0.9389）**——解冻后能适配任务差异。
3. **从零训练在两者下都明显更差**（0.6947 / 0.7889）。
4. 预训练任务 A 与目标 B **相关但不同**（条纹方向 + 亮度偏移）⇒ 迁移有效。

## 6. 数学表达式

**为什么小数据下微调会过拟合**

微调的可训练参数 $P_{\text{all}}\gg N$：

本课 CNN 卷积+FC 约 1,000+ 参数，而 $N=10$ ⇒ $P/N\gg1$ ⇒ 容易记住训练集。

**冻结时**可训练参数只有分类头（$16\times2\times2\times1+1=65$）⇒ 远小于 $N$ 的约束，反而稳。

## 7. 数学推导

**决定"冻结还是微调"的经验规则**

设目标域样本数 $N_{\text{target}}$、与预训练域的相似度 $S$：

| 数据量 | 相似度高 | 相似度低 |
|---|---|---|
| **少**（<1k） | 冻结特征 | 冻结 + 只训浅层 |
| **中**（1k–10k） | 微调后半部分 | 微调全部（小 lr） |
| **多**（>10k） | 微调全部 | 从头训 |

**本课对应**：$N=10$（少）、相似度中高 ⇒ **冻结最优**；$N=20$ 时微调开始反超。

## 8. 结构示意图

```mermaid
flowchart LR
    A["预训练 backbone<br/>(冻结/解冻)"] --> B["分类头（新）"]
    B --> C["输出 C 类"]
    D["数据 + 增强"] --> A
    C --> E["验证集调 lr/epochs"]
    E --> F["测试集评估（一次）"]
```

## 9. 具体计算示例

```text
任务 A（400 样本）预训练 → acc 1.0
任务 B（10 样本）：
  从零    ：0.6947
  冻结卷积：0.8789
  全量微调：0.8632

任务 B（20 样本）：
  从零 0.7889 / 冻结 0.8333 / 微调 0.9389
```

## 10. Python 实现

```python
import torch
import torch.nn as nn


def make_cnn() -> nn.Sequential:
    return nn.Sequential(
        nn.Conv2d(1, 8, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
        nn.Conv2d(8, 16, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
        nn.Flatten(),
        nn.Linear(16 * 2 * 2, 1),
    )


def freeze_backbone(model: nn.Sequential) -> None:
    """冻结除最后一层外的全部参数。"""
    for p in model[:-1].parameters():
        p.requires_grad = False


model = make_cnn()
freeze_backbone(model)
trainable = [p for p in model.parameters() if p.requires_grad]
print("可训练参数个数:", sum(p.numel() for p in trainable))
print("全部参数个数  :", sum(p.numel() for p in model.parameters()))
```

## 11. PyTorch 实现（冻结 vs 微调）

```python
import torch
import torch.nn as nn
import torch.nn.functional as F


def build() -> nn.Sequential:
    return nn.Sequential(
        nn.Conv2d(1, 8, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
        nn.Conv2d(8, 16, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
        nn.Flatten(), nn.Linear(16 * 2 * 2, 1),
    )


def train(model: nn.Sequential, X, y, lr: float, epochs: int = 60):
    params = [p for p in model.parameters() if p.requires_grad]
    opt = torch.optim.Adam(params, lr=lr)
    for _ in range(epochs):
        opt.zero_grad()
        F.binary_cross_entropy_with_logits(model(X), y).backward()
        opt.step()
    return model


# 冻结
frozen = build()
for p in frozen[:-1].parameters():
    p.requires_grad = False

# 微调
finetune = build()
for p in finetune.parameters():
    p.requires_grad = True

print("冻结版可训练参数:", sum(p.numel() for p in frozen.parameters() if p.requires_grad))
print("微调版可训练参数:", sum(p.numel() for p in finetune.parameters() if p.requires_grad))

# 实际用法：
# train(frozen, Xb_tr, yb_tr, lr=1e-2)   # 冻结：只用较大 lr 训头部
# train(finetune, Xb_tr, yb_tr, lr=1e-3) # 微调：整体用小 lr
```

## 12. 代码逐行解释

| 代码 | 作用 |
|---|---|
| `p.requires_grad = False` | 冻结参数（不更新、不占优化器状态） |
| `model[:-1]` | 除最后一层（分类头）外的全部 |
| `filter(lambda p: p.requires_grad, ...)` | 只把可训练参数交给优化器 |
| 冻结 lr 大、微调 lr 小 | 冻结时只需训头；微调要保护预训练特征 |
| `load_state_dict(pretrained)` | 载入预训练权重（本课用同结构自造预训练） |

**关键**：冻结后**优化器不要传全部参数**，否则会浪费内存且可能意外更新。

## 13. 实际运行结果

```text
预训练(A) test acc: 1.0
从零训练(B, 40 样本) → 本课最终采用更难设置后：
从零(B)    test acc: 0.6947
冻结卷积(B) test acc: 0.8789
全量微调(B) test acc: 0.8632
```

（注：早期较简单的设置下三种方法都能到 1.0，说明**任务太容易时迁移学习看不出优势**；本课最终用"10 样本 + 噪声 1.2"才拉开差距，这一点已如实记录。）

## 14. 应用场景

| 场景 | 做法 |
|---|---|
| 医学影像（数据少） | 冻结 ImageNet backbone + 新头 |
| 工业缺陷检测 | 微调后半段 + 强增强 |
| 细粒度分类（鸟/花） | 微调全部，小 lr |
| 与 ImageNet 差异极大（卫星/红外） | 从头训或只迁移浅层 |
| 快速基线 | 冻结特征 + 逻辑回归头 |

## 15. 优点与缺点

| 做法 | 优点 | 缺点 |
|---|---|---|
| 冻结特征 | 快、稳、省显存 | 上限受预训练特征限制 |
| 微调 | 上限高、可适配差异 | 易过拟合、需调 lr |
| 从头训 | 完全贴合任务 | 需大量数据与算力 |

## 16. 常见错误

| 错误 | 现象 | 纠正 |
|---|---|---|
| 冻结后仍传全部参数给优化器 | 内存浪费/意外更新 | 只传 `requires_grad=True` |
| 微调用大 lr | 预训练特征被破坏 | 用 1e-4–1e-3 |
| 忘记替换分类头 | 输出类别数不对 | 换 `Linear(..., C)` |
| 归一化方式与预训练不一致 | 精度掉很多 | 用相同 mean/std |
| 任务太简单还迁移 | 看不出差别（本课早期） | 用更难/更少数据评估 |
| 用测试集选"冻结 or 微调" | 泄漏 | 用验证集 |

## 17. 本节总结

- 三种做法：**冻结特征 / 微调 / 从头训**；本课 10 样本下 **0.8789 vs 0.6947**。
- 数据极少 ⇒ 冻结更稳；数据稍多 ⇒ 微调更强（20 样本时 **0.9389**）。
- 工作流：数据→增强→预训练 backbone→新头→验证调参→测试一次。

## 练习与参考答案

**基础 1**：迁移学习的三种做法是什么？各适合什么数据量。

**基础 2**：本课"从零 / 冻结 / 微调"的准确率各是多少？

**进阶 1**：为什么数据极少时"冻结"反而优于"微调"？

**综合**：你有 800 张医学影像要分 5 类，与 ImageNet 差异较大。请给出完整的迁移学习方案（含 lr、冻结策略、增强、评估）。

> [!success]- 参考答案

> **基础 1**
> - **冻结特征**：只训分类头，适合**数据少 + 任务相似**。
> - **微调**：解冻部分/全部，小 lr，适合**数据中等 + 有差异**。
> - **从头训**：不用预训练，适合**数据大 + 差异极大**。

> **基础 2**
> 从零 **0.6947**、冻结 **0.8789**、微调 **0.8632**（10 样本设置）。

> **进阶 1**
> 因为微调的可训练参数远多于样本数（$P\gg N$），容易把 10 个样本"记住"而不泛化。
> 冻结时只有分类头可训练（本课 65 个参数），约束强、不易过拟合；而卷积特征本身已足够好。
> 实测印证：10 样本时冻结 0.8789 > 微调 0.8632；20 样本时微调反超（0.9389 vs 0.8333）。

> **综合（参考）**
> **方案**：
> 1. **backbone**：ResNet-18/34 预训练（ImageNet），替换 `fc` 为 `Linear(512, 5)`；
> 2. **冻结策略**：先冻结全部卷积，只训头 5–10 epoch（建立稳定分类头）；再解冻 `layer3/layer4` 微调；
> 3. **学习率**：头部 1e-3，backbone 1e-4（分组设置 `param_groups`）；加 warmup + cosine；
> 4. **增强**：随机裁剪、水平翻转（医学影像慎用，取决于语义）、亮度/对比度扰动、CutMix；
> 5. **正则**：Weight Decay 1e-4、label smoothing 0.1、早停（patience 5）；
> 6. **评估**：5 折分层 CV 或固定验证集；指标用 macro-F1 + AUC（类别不平衡时）；
> 7. **注意**：归一化必须与预训练一致（ImageNet mean/std）；医学影像常需**单通道→3 通道复制**。
> **验证**：用验证集比较"冻结 vs 微调"，不要用测试集。
