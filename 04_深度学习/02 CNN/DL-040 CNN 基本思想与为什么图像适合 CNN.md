# DL-040 CNN 基本思想与为什么图像适合 CNN

## 1. 本节学习目标

1. 说清图像的两个关键性质：**局部相关性**与**平移不变性**。
2. 用实测看全连接与卷积的参数量差（**196,672 vs 1,792，109.8 倍**）。
3. 用实测看"平移后卷积响应跟着平移，而全连接输出大幅变化"（0.5667 → 0.1835）。
4. 理解 CNN 的三个核心设计：**局部连接、权重共享、层次化表示**。

## 2. 为什么需要这个知识

因为**直接用全连接层处理图像会立刻爆掉**：

一张 $3\times32\times32$ 的图展平是 3072 维，接到 64 个单元就要 **196,672** 个参数；而同样输入输出，一个 $3\times3$ 卷积只要 **1,792** 个。

这不是"省参数"的小优化，而是**能不能训得动**的分水岭。

## 3. 直观解释

**图像的两个性质**：

| 性质 | 含义 | CNN 的应对 |
|---|---|---|
| **局部相关** | 相邻像素才有强关系，远处像素关系弱 | 只连局部（$3\times3$ 窗口） |
| **平移不变** | 猫在左上或右下，都是猫 | 同一个卷积核滑过全图（权重共享） |

**类比**：找"猫耳朵"的小图案，不需要为图像的每个位置各学一个检测器——**一个检测器滑遍全图**就够了。

## 4. 正式定义

**卷积层**

$$
y_{i,j,k}=\sum_{c=1}^{C_{in}}\sum_{u=0}^{K-1}\sum_{v=0}^{K-1}
w_{k,c,u,v}\,x_{c,\,i+u,\,j+v}+b_k
$$

**参数量**

$$
\#\text{params}=K^2\cdot C_{in}\cdot C_{out}+C_{out}
$$

**全连接层参数量**

$$
\#\text{params}=HWC_{in}\cdot n_{out}+n_{out}
$$

## 5. 核心原理

**本课实测 1：参数量**

```text
FC(3072→64) 参数: 196672
Conv2d(3,64,3,pad=1) 参数: 1792
比值: 109.8
```

**计算**：

- FC：$3072\times64+64=196{,}672$
- Conv：$3^2\times3\times64+64=1{,}728+64=1{,}792$

**本课实测 2：平移敏感性**

```text
原图 conv 非零位置: [[2, 2], [3, 3]]
平移后 conv 非零位置: [[3, 3], [4, 4]]
响应值相同: True
FC 输出(原/平移): 0.5667 0.1835  差异: 0.3832
```

**读法**：

1. 把亮点从 $(2,2)$ 挪到 $(3,3)$，**卷积响应的位置也跟着平移**，且数值完全相同（`True`）。
2. 而**全连接输出从 0.5667 变到 0.1835**（差 0.3832）——因为它把每个位置当独立特征，位置一变特征全变。

**这就是"平移不变性 vs 位置敏感"的定量对比。**

## 6. 数学表达式

**权重共享的含义**

同一层里，$w_{k,c,u,v}$ 对**所有空间位置 $(i,j)$ 复用**。

因此参数与图像大小**无关**：$32\times32$ 和 $512\times512$ 的图，只要 $K,C_{in},C_{out}$ 相同，参数量一样。

**感受野**：单层 $3\times3$ 只能看到 $3\times3$；堆 $L$ 层后感受野约 $(2L+1)\times(2L+1)$（stride=1 时）。

## 7. 数学推导

**为什么共享权重能"省"这么多参数**

全连接：每个输入像素到每个输出单元都有独立权重 ⇒ 参数 $\propto HWC$。
卷积：权重只在 $K\times K$ 窗口内定义，且跨位置共享 ⇒ 参数 $\propto K^2C$。

比值：

$$
\frac{\text{FC}}{\text{Conv}}=\frac{HWC_{in}C_{out}}{K^2C_{in}C_{out}}=\frac{HW}{K^2}
$$

本课：$32\times32/3^2=1024/9\approx113.8$，与实测 109.8 同量级（差异来自偏置项与小图）。

## 8. 结构示意图

```mermaid
flowchart LR
    A["图像 3×32×32"] --> B["卷积 3×3,64"]
    B --> C["Feature Map 64×32×32"]
    C --> D["池化/下采样"]
    D --> E["更深卷积"]
    E --> F["全局池化 → 分类头"]
```

## 9. 具体计算示例

```text
FC：3072 × 64 + 64 = 196,672
Conv：3×3 × 3 × 64 + 64 = 1,792
倍数：109.8

平移实验：
  亮点 (2,2) → (3,3)
  Conv 响应位置：(2,2),(3,3) → (3,3),(4,4)   数值相同
  FC 输出：0.5667 → 0.1835（差 0.3832）
```

## 10. Python 实现

```python
import torch
import torch.nn as nn

img = torch.randn(1, 3, 32, 32)
fc = nn.Linear(3 * 32 * 32, 64)
conv = nn.Conv2d(3, 64, kernel_size=3, padding=1)

print("FC 参数:", sum(p.numel() for p in fc.parameters()))
print("Conv 参数:", sum(p.numel() for p in conv.parameters()))
print("FC 输出:", tuple(fc(img.flatten(1)).shape))
print("Conv 输出:", tuple(conv(img).shape))
```

## 11. PyTorch 实现（平移对比）

```python
import torch
import torch.nn.functional as F

x = torch.zeros(1, 1, 8, 8)
x[0, 0, 2, 2] = 1.0
k = torch.tensor([[[[1., 0., 0.], [0., -1., 0.], [0., 0., 0.]]]])

x_shift = torch.zeros(1, 1, 8, 8)
x_shift[0, 0, 3, 3] = 1.0

c1 = F.conv2d(x, k, padding=1)
c2 = F.conv2d(x_shift, k, padding=1)
print("原图非零位置:", (c1[0, 0] != 0).nonzero().tolist())
print("平移后非零位置:", (c2[0, 0] != 0).nonzero().tolist())
print("响应最大值相同:", float(c1.max()) == float(c2.max()))

torch.manual_seed(0)
w = torch.randn(1, 64)
print("FC 输出(原/平移):",
      round(float(w @ x.flatten(1).T), 4),
      round(float(w @ x_shift.flatten(1).T), 4))
```

## 12. 代码逐行解释

| 代码 | 作用 |
|---|---|
| `nn.Linear(3072, 64)` | 全连接基线（每个像素独立权重） |
| `nn.Conv2d(3, 64, 3, padding=1)` | 卷积（3×3 窗口 + 权重共享） |
| `p.numel()` | 参数量 |
| `F.conv2d(x, k, padding=1)` | 手动卷积，验证平移性 |
| `(c!=0).nonzero()` | 找响应位置 |
| `w @ x.flatten(1).T` | 模拟全连接输出 |

**关键**：卷积输出形状是 `(N, C_out, H, W)`——**保留了空间维度**，这是平移性质能体现的前提。


## 14. 应用场景

| 场景 | 为什么用 CNN |
|---|---|
| 图像分类 | 局部图案 + 平移不变 |
| 目标检测 | 同上 + 多尺度 |
| 语义分割 | 保留空间维度 |
| 医学影像 | 局部纹理关键 |
| 一维信号（音频/EEG） | 1D 卷积同样适用 |

## 15. 优点与缺点

| 优点 | 缺点 |
|---|---|
| 参数少（本课 109.8 倍差距） | 只对"局部 + 平移"结构有效 |
| 保留空间结构 | 大核/深网计算量大 |
| 层次化特征（边缘→部件） | 对旋转/尺度不天然不变（需增强/特殊结构） |

## 16. 常见错误

| 错误 | 现象 | 纠正 |
|---|---|---|
| 图像直接展平接 FC | 参数爆炸、过拟合 | 先卷积 |
| 以为 CNN 天然旋转不变 | 旋转后性能掉 | 用旋转增强 |
| 忘记 `padding` | 每层尺寸缩小 | `padding=K//2` 保尺寸 |
| 混淆 `NCHW` 与 `NHWC` | 形状报错 | PyTorch 用 NCHW |
| 认为卷积一定比 FC 好 | 表格数据上未必 | 看数据结构 |

## 17. 本节总结

- 图像有**局部相关 + 平移不变** ⇒ 卷积的**局部连接 + 权重共享**正好匹配。
- 本课参数量：FC **196,672** vs Conv **1,792**（**109.8 倍**）。
- 平移实验：卷积响应**跟着平移、数值不变**；FC 输出从 0.5667 变成 0.1835。

## 练习与参考答案

**基础 1**：CNN 的三个核心设计是什么？分别对应图像的什么性质？

**基础 2**：本课 FC 与 Conv 的参数量各是多少？倍数多少？

**进阶 1**：为什么"权重共享"能让参数量与图像尺寸无关？

**综合**：输入是 $3\times224\times224$ 的图像，第一层要输出 64 通道。若用全连接，参数量是多少？用 $7\times7$ 卷积（stride=2, padding=3）呢？

> [!success]- 参考答案

> **基础 1**
> - **局部连接** ↔ 图像的局部相关性（相邻像素关系强）。
> - **权重共享** ↔ 平移不变性（同一图案出现在哪都该被同一检测器识别）。
> - **层次化表示** ↔ 图像由边缘→纹理→部件的组合结构。

> **基础 2**
> FC **196,672**；Conv **1,792**；倍数 **109.8**。

> **进阶 1**
> 因为同一个卷积核在**所有空间位置复用**：参数只在 $K\times K\times C_{in}\times C_{out}$ 上定义，与 $H,W$ 无关。
> 全连接的权重数 $\propto HWC_{in}C_{out}$，随图像尺寸线性（平方）增长；卷积是常数。
> 本课比值 $HW/K^2=32^2/9\approx113.8$，与实测 109.8 同量级。

> **综合（参考）**
> **全连接**：输入 $3\times224\times224=150{,}528$，输出 64 ⇒
> $$150528\times64+64=9{,}633{,}856$$
> **卷积 $7\times7$、stride=2、padding=3**：
> $$7^2\times3\times64+64=9{,}408+64=9{,}472$$
> 倍数约 **1017 倍**。
> **输出尺寸**：$\lfloor(224+6-7)/2\rfloor+1=112$ ⇒ `(1, 64, 112, 112)`。
> 这就是为什么 ResNet 第一层用 $7\times7$ 卷积 + stride 2，而不是全连接。
