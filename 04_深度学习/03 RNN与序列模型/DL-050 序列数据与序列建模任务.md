# DL-050 序列数据与序列建模任务

## 1. 本节学习目标

1. 说清序列数据的三个维度：**batch、时间步、特征**（`(B, T, C)`）。
2. 会处理**变长序列**：padding + mask（本课实测掩码求和/均值）。
3. 分清五类序列任务（分类、回归、标注、生成、翻译）。
4. 知道"为什么不能直接把序列当表格喂给 MLP"。

## 2. 为什么需要这个知识

因为序列数据**有顺序、长度可变、还有长程依赖**——这三点让"打平接全连接"失效：

- 打平后位置信息变成独立特征，模型学不到"前后关系"；
- 变长序列打平后维度不一致，无法成批；
- 长程依赖（第 1 步影响第 50 步）需要**状态传递**机制。

## 3. 直观解释

**序列张量 `(B, T, C)`**：

```text
B：几句/几条序列
T：每条的步数（时间步）
C：每步的特征维度
```

**本课例子**：`(2, 3, 1)` = 2 条序列、每 3 步、每步 1 维。

**"变长"怎么批处理**：短的补 0（padding）到同长，同时用 mask 标记哪些是"真数据"。

## 4. 正式定义

**序列输入**

$$
\mathbf{X}\in\mathbb{R}^{B\times T\times C}
$$

**掩码**

$$
m_{b,t}\in\{0,1\},\qquad
\bar{\mathbf{x}}_b=\frac{\sum_t m_{b,t}\mathbf{x}_{b,t}}{\sum_t m_{b,t}}
$$

**五类任务**

| 任务 | 输入 → 输出 | 例 |
|---|---|---|
| 序列分类 | $(B,T,C)\to(B,K)$ | 情感分析 |
| 序列回归 | $(B,T,C)\to(B,1)$ | 股价预测 |
| 序列标注 | $(B,T,C)\to(B,T,K)$ | 词性标注 |
| 序列生成 | $(B,T,C)\to(B,T',C)$ | 文本生成 |
| 序列到序列 | $(B,T,C)\to(B,T',C')$ | 机器翻译 |

## 5. 核心原理

**本课实测（掩码统计）**

```text
形状 (B,T,C): (2, 3, 1)
有效步数: [3, 2]

按掩码求和: [6.0, 9.0]
按掩码均值: [2.0, 4.5]
```

**读法**：

- 第 1 条序列是 `[1,2,3]` ⇒ 和 6、均值 2.0。
- 第 2 条是 `[4,5,0]`，但**有效步数 2**（第 3 步是 padding）⇒ 和 9（4+5+0）、均值 **4.5**（9/2，**不是 9/3**）。

**关键**：如果不用 mask，均值会变成 3.0——**padding 拉低了统计量**，这是序列任务最常见的静默 bug。

## 6. 数学表达式

**为什么必须除以"有效长度"**

$$
\bar x=\frac{\sum_{t=1}^{T}m_tx_t}{\sum_{t=1}^{T}m_t}
\quad\text{而不是}\quad
\frac{1}{T}\sum_{t=1}^{T}x_t
$$

本课：$9/2=4.5$ vs $9/3=3.0$ —— 差 1.5。

**掩码在损失里**

$$
L=\frac{\sum_{b,t}m_{b,t}\,\ell(\hat y_{b,t},y_{b,t})}{\sum_{b,t}m_{b,t}}
$$

## 7. 数学推导

**为什么"打平 + MLP"处理序列会失败**

设序列长度 $T$，打平后维度 $T\times C$。两个问题：

1. **位置错位**：把序列整体平移一步，打平后的向量完全不同 ⇒ MLP 需为每个位置单独学权重（参数 $\propto T$）。
2. **长度不一致**：$T=5$ 与 $T=10$ 的输入维度不同 ⇒ 无法用同一模型。

**RNN/CNN 的解法**：在时间维上**共享参数**（类似 CNN 在空间维共享），使参数量与 $T$ 解耦。

## 8. 结构示意图

```mermaid
flowchart LR
    A["原始序列<br/>变长"] --> B["padding 到 T_max"]
    B --> C["生成 mask"]
    C --> D["模型 (RNN/CNN/Transformer)"]
    D --> E["按 mask 聚合/损失"]
```

## 9. 具体计算示例

```text
X = [[[1],[2],[3]],
     [[4],[5],[0]]]        # 第 2 条第 3 步是 padding
mask = [[1,1,1],[1,1,0]]

有效步数 = [3, 2]
掩码求和 = [6.0, 9.0]
掩码均值 = [2.0, 4.5]     # 9/2 而非 9/3
```

## 10. Python 实现

```python
import torch

x = torch.tensor([[[1.], [2.], [3.]],
                  [[4.], [5.], [0.]]])          # (B=2, T=3, C=1)
mask = torch.tensor([[1, 1, 1], [1, 1, 0]])     # (B, T)

print("形状 (B,T,C):", tuple(x.shape))
print("有效步数:", mask.sum(dim=1).tolist())

xs = x.squeeze(-1) * mask
print("按掩码求和:", xs.sum(dim=1).tolist())
print("按掩码均值:", (xs.sum(dim=1) / mask.sum(dim=1)).tolist())
print("错误均值(除以 T):", (xs.sum(dim=1) / x.shape[1]).tolist())
```

## 11. PyTorch 实现（padding 与 pack）

```python
import torch
from torch.nn.utils.rnn import pack_padded_sequence, pad_packed_sequence

seqs = [torch.randn(3, 4), torch.randn(5, 4)]     # 长度 3 与 5
lengths = torch.tensor([3, 5])

padded = torch.nn.utils.rnn.pad_sequence(seqs, batch_first=True)
print("padding 后形状:", tuple(padded.shape))      # (2, 5, 4)

packed = pack_padded_sequence(padded, lengths, batch_first=True, enforce_sorted=False)
print("packed 数据类型:", type(packed).__name__)

out, _ = pad_packed_sequence(packed, batch_first=True)
print("解包后形状:", tuple(out.shape))
```

## 12. 代码逐行解释

| 代码 | 作用 |
|---|---|
| `(B,T,C)` | 序列张量标准形状 |
| `mask.sum(dim=1)` | 每条序列的有效步数 |
| `x * mask` | 把 padding 位置置零 |
| `sum / mask.sum` | **正确的掩码均值** |
| `pad_sequence` | 自动补到最长 |
| `pack_padded_sequence` | 让 RNN **跳过 padding** 计算 |

**为什么要 pack**：不 pack 时 RNN 会在 padding 上也推进隐状态，**污染最终状态**。

## 13. 实际运行结果

```text
形状 (B,T,C): (2, 3, 1)
有效步数: [3, 2]
按掩码求和: [6.0, 9.0]
按掩码均值: [2.0, 4.5]
```

## 14. 应用场景

| 数据 | T | C |
|---|---|---|
| 文本 token ids | 句长 | 1（id）或 D（embedding） |
| 股票日线 | 天数 | 5（OHLCV） |
| 传感器 | 采样点数 | 通道数 |
| 音频帧 | 帧数 | 梅尔频带数 |
| 视频 | 帧数 | 3×H×W（或特征） |

## 15. 优点与缺点

| 优点 | 缺点 |
|---|---|
| 保留顺序信息 | 变长处理复杂（padding/mask） |
| 参数量可与 T 解耦 | 长序列显存/计算大 |
| 支持多类任务 | 长程依赖难（RNN） |

## 16. 常见错误

| 错误 | 现象 | 纠正 |
|---|---|---|
| 序列打平接 MLP | 参数爆炸、丢失顺序 | 用 RNN/CNN/Transformer |
| 忘记 mask | 均值/损失被 padding 拉偏（本课 4.5 vs 3.0） | 除有效长度 |
| 不 pack 直接喂 RNN | 最终状态被 padding 污染 | `pack_padded_sequence` |
| 混淆 `(B,T,C)` 与 `(T,B,C)` | 形状报错 | `batch_first=True` |
| 用未来信息 | 泄漏 | 因果掩码（生成任务） |

## 17. 本节总结

- 序列张量 `(B,T,C)`；变长要 **padding + mask**。
- 掩码均值必须除**有效步数**：本课 9/2 = **4.5**，不是 9/3 = 3.0。
- 五类任务：分类、回归、标注、生成、翻译。

## 练习与参考答案

**基础 1**：序列张量 `(B,T,C)` 三个维度各是什么？为什么不能直接打平喂 MLP？

**基础 2**：本课的掩码求和与掩码均值各是多少？为什么不是 3.0？

**进阶 1**：为什么 RNN 需要 `pack_padded_sequence`？

**综合**：一批文本序列长度为 `[5, 12, 8]`，特征维度 300。请写出 padding 后的形状、mask 形状，并说明如何正确计算整批的平均池化表示。

> [!success]- 参考答案

> **基础 1**
> - B：batch 大小（几条序列）；T：时间步数；C：每步特征维度。
> - 打平后位置信息变成独立特征（模型学不到顺序），且变长序列维度不一致，无法成批/共享参数。

> **基础 2**
> 求和 `[6.0, 9.0]`；均值 `[2.0, 4.5]`。
> 第 2 条只有 **2** 个有效步（`[4,5]`，第 3 个是 padding 0），所以 $9/2=4.5$；若除 $T=3$ 会得 3.0，**被 padding 拉低**。

> **进阶 1**
> 不 pack 时，RNN 会把 padding 的位置也逐步推进隐状态，导致最终隐状态受"补零"影响（尤其变长差异大时）。
> `pack` 会按真实长度组织计算，让 RNN 在每条序列的有效步后停止，输出更准确。

> **综合（参考）**
> - padding 后形状：`(3, 12, 300)`（补到最长 12）。
> - mask 形状：`(3, 12)`，值为
> ```text
> [[1]*5 + [0]*7,
>  [1]*12,
>  [1]*8 + [0]*4]
> ```
> - 平均池化（自包含示例）：
> ```python
> import torch
>
> lengths = [5, 12, 8]
> T, C = 12, 300
> out = torch.randn(len(lengths), T, C)
> mask = torch.zeros(len(lengths), T)
> for i, n in enumerate(lengths):
>     mask[i, :n] = 1.0
>
> masked = out * mask.unsqueeze(-1)                     # (3,12,300)
> pooled = masked.sum(1) / mask.sum(1, keepdim=True)    # (3,300)
> print("pooled 形状:", tuple(pooled.shape))
> print("分母(有效步数):", mask.sum(1).tolist())
> ```
> **关键**：分母是 `mask.sum(1)`（5/12/8），不是 12。
